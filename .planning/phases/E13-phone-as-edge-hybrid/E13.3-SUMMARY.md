# Phase E13.3 Plan E13.3: Termux Bundle Scripts Summary

## Objective
Create all Termux runtime scripts and build scripts for the phone edge device. Scripts handle bootstrapping Termux packages, starting/stopping the Nginx+PHP-FPM+scheduler stack, and building `edge-bundle.tgz` that gets embedded in the APK.

## What Was Built

### Termux Runtime Scripts (`scripts/edge/setup/phone/`)

| File | Purpose |
|------|---------|
| `bootstrap.sh` | Idempotent package installer; runs inside Termux on device |
| `start-stack.sh` | Start Nginx + PHP-FPM + scheduler with 30s health check |
| `stop-stack.sh` | Stop all services (nginx, php-fpm, scheduler) |
| `boot.sh` | Termux boot hook installed to ~/.termux/boot/ |
| `nginx.conf` | Nginx config listening on 127.0.0.1:8000, no daemon off |
| `php-fpm.conf` | PHP-FPM pool config (ondemand, max_children=4) |
| `termux.properties` | allow-external-apps=true for Capacitor integration |
| `cron.crontab` | Fallback cron-based scheduler |

### Build Scripts (`scripts/edge/build/phone/`)

| File | Purpose |
|------|---------|
| `package-edge-termux.sh` | Bundle Laravel app + Termux scripts into edge-bundle.tgz |
| `build-apk.sh` | Full APK pipeline: Vite build + bundle + cap sync + gradle |

### Key Design Decisions

- **php-fpm.conf appended to $PREFIX/etc/php-fpm.conf** — Termux does not use php-fpm.d/www.conf like Debian; the main config file is the only one read
- **No `daemon off;` in nginx.conf** — termux-services (runit) supervises nginx and expects it to daemonize; daemon off causes double-start
- **localhost-only Nginx (127.0.0.1:8000)** — Phone is edge device with no external incoming traffic; Capacitor WebView loads localhost
- **Config cache happens on-device in start-stack.sh** — NOT during bundle packaging; ensures .env.edge values are used, not dev .env values
- **F-Droid Termux only** — Documented in bootstrap.sh; Play Store version is obsolete
