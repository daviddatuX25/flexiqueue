# E13.5 — Foreground Service + Wake Lock Summary

## One-liner

Foreground service with wake lock prevents Android Doze from killing PHP-FPM on Samsung A56 5G.

## What was built

### Android Native Layer

**PowerGuardPlugin.java** - Capacitor plugin with two methods:
- `startGuard()`: Acquires PARTIAL_WAKE_LOCK and starts foreground service
- `stopGuard()`: Releases wake lock and stops the service

**PowerGuardService.java** - Foreground service that:
- Creates notification channel on `onCreate()`
- Shows persistent notification "FlexiQueue Edge - Edge device running"
- Returns `START_STICKY` so Android restarts if killed
- Handles STOP action to gracefully shut down

**BootReceiver.java** - BroadcastReceiver that:
- Listens for `android.intent.action.BOOT_COMPLETED`
- Starts `PowerGuardService` automatically on device boot

### AndroidManifest.xml additions
```xml
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_SPECIAL_USE" />
<uses-permission android:name="android.permission.WAKE_LOCK" />
<uses-permission android:name="android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS" />

<service android:name=".PowerGuardService"
    android:foregroundServiceType="specialUse"
    android:exported="false">
    <property android:name="android.app.PROPERTY_SPECIAL_USE_FGS_SUBTYPE"
        android:value="Keeps local edge server alive for offline queue operations" />
</service>

<receiver android:name=".BootReceiver" android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.BOOT_COMPLETED" />
    </intent-filter>
</receiver>
```

### MainActivity changes
- Starts `PowerGuardService` on app launch
- Registers `PowerGuardPlugin`
- Requests battery optimization exemption once via `SharedPreferences`

### TypeScript wrapper
`resources/js/native/plugins/powerGuard.ts` - provides `startPowerGuard()`, `stopPowerGuard()`, `isPowerGuardActive()` for Capacitor JS layer.
